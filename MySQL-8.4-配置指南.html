MySQL 8.4 配置指南

安装路径：F:\Tools\mysql-8.4.8-winx64  |  版本：8.4.8 (winx64)

1. 初始化 MySQL

以管理员身份打开 CMD 或 PowerShell，进入 bin 目录：

cd F:\Tools\mysql-8.4.8-winx64\bin

初始化数据目录，生成 root 临时密码：

mysqld --initialize --console

执行后会输出：

[Server] A temporary password is generated for root@localhost: aB3x!pQr9#sZ
注意：务必记下这个临时密码，首次登录必须要用。

2. 安装 Windows 服务

以管理员身份执行：

cd F:\Tools\mysql-8.4.8-winx64\bin
mysqld --install MySQL84

输出：Service successfully installed.

自定义服务名

mysqld --install MySQL8.4

删除服务

mysqld --remove MySQL84

3. 启动 / 停止 MySQL

方式启动停止重启
CMDnet start MySQL84net stop MySQL84—
PowerShellStart-Service MySQL84Stop-Service MySQL84Restart-Service MySQL84
服务管理器Win+R → services.msc → 右键操作

4. 登录 MySQL

cd F:\Tools\mysql-8.4.8-winx64\bin
mysql -u root -p

输入初始化时生成的临时密码。首次登录后必须先改密码：

ALTER USER 'root'@'localhost' IDENTIFIED BY 'YourNewPassword123!';
FLUSH PRIVILEGES;

5. 修改 root 密码

ALTER USER 'root'@'localhost' IDENTIFIED BY 'NewPassword123!';

忘记密码 —— 重置方法

  1. 停止 MySQL 服务
    net stop MySQL84
  2. 跳过权限验证启动
    mysqld --skip-grant-tables --console

    保持此窗口不要关闭。

  3. 新开 CMD，无密码登录
    mysql -u root
  4. 重置密码
    FLUSH PRIVILEGES;
ALTER USER 'root'@'localhost' IDENTIFIED BY 'NewPassword123!';
  5. 关闭 skip-grant-tables 窗口，重新启动服务
    net start MySQL84

某个库全部权限GRANT ALL PRIVILEGES ON mydb.* TO 'myuser'@'localhost';

操作命令

7. 配置文件 my.ini

在 F:\Tools\mysql-8.4.8-winx64\ 下创建 my.ini：

[mysqld]
# 基础设置
port=3306
basedir=F:/Tools/mysql-8.4.8-winx64
datadir=F:/Tools/mysql-8.4.8-winx64/data

# 字符集
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci

# 连接设置
max_connections=200
max_connect_errors=100

# 日志
log-error=F:/Tools/mysql-8.4.8-winx64/data/mysql-error.log
general-log=0

# InnoDB
innodb_buffer_pool_size=256M
innodb_log_file_size=64M

# 认证插件（兼容旧客户端）
default_authentication_plugin=mysql_native_password

[mysql]
default-character-set=utf8mb4

[client]
default-character-set=utf8mb4
注意：路径必须用正斜杠 /，不要用反斜杠 \。修改后需重启服务。

9. 数据库操作

创建数据库

-- 基础创建
CREATE DATABASE mydb;

-- 指定字符集和排序规则（推荐）
CREATE DATABASE mydb
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

-- 仅当不存在时创建
CREATE DATABASE IF NOT EXISTS mydb
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

查看 / 选择 / 修改 / 删除

操作命令
列出所有数据库SHOW DATABASES;
查看建库语句SHOW CREATE DATABASE mydb;
选择数据库USE mydb;
修改字符集ALTER DATABASE mydb CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
删除数据库DROP DATABASE IF EXISTS mydb;
⚠️ DROP DATABASE 不可恢复，请谨慎操作。

字符集选择

字符集说明推荐
utf8mb4完整 UTF-8，支持 emoji✅ 推荐
utf8MySQL 阉割版，最多 3 字节❌ 不推荐
gbk中文编码仅兼容老系统
latin1西欧编码仅特殊场景

常用排序规则

排序规则大小写说明
utf8mb4_unicode_ci不区分 ✅Unicode 标准排序，推荐
utf8mb4_general_ci不区分快速但不精确
utf8mb4_bin区分二进制比较，区分大小写

10. 表操作

创建表（完整示例）

CREATE TABLE users (
  id         INT AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
  username   VARCHAR(50)  NOT NULL UNIQUE COMMENT '用户名',
  email      VARCHAR(100) NOT NULL COMMENT '邮箱',
  age        TINYINT UNSIGNED DEFAULT 0 COMMENT '年龄',
  balance    DECIMAL(10,2) DEFAULT 0.00 COMMENT '余额',
  is_active  TINYINT(1) DEFAULT 1 COMMENT '是否激活',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_username (username),
  INDEX idx_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';

常用字段类型

类型用途示例
INT整数age INT
BIGINT大整数（ID）id BIGINT AUTO_INCREMENT
TINYINT(1)布尔值is_deleted TINYINT(1) DEFAULT 0
VARCHAR(N)变长字符串name VARCHAR(100)
TEXT / LONGTEXT长文本content TEXT
DECIMAL(M,D)精确小数（金额）price DECIMAL(10,2)
DATETIME日期时间created_at DATETIME
DATE日期birthday DATE
JSONJSON 对象extra JSON

修改表结构

操作命令
添加列ALTER TABLE users ADD COLUMN phone VARCHAR(20) AFTER email;
修改列类型ALTER TABLE users MODIFY COLUMN username VARCHAR(80);
重命名列ALTER TABLE users CHANGE COLUMN phone mobile VARCHAR(20);
删除列ALTER TABLE users DROP COLUMN age;

查看表

操作命令

查看建表语句SHOW CREATE TABLE users;
查看表详情SHOW TABLE STATUS;

删除与清空

操作命令可回滚
删除表DROP TABLE IF EXISTS users;❌

清空表（可回滚）DELETE FROM users;✅

索引操作

操作命令
创建普通索引CREATE INDEX idx_name ON users (username);
创建唯一索引CREATE UNIQUE INDEX uk_email ON users (email);

查看索引SHOW INDEX FROM users;

11. 备份与恢复

mysqldump 备份常用命令

场景命令（CMD 下执行）
备份单个库mysqldump -u root -p --databases mydb > D:\backup\mydb.sql
备份所有库mysqldump -u root -p --all-databases > D:\backup\all.sql
只备份表结构mysqldump -u root -p --no-data mydb > D:\backup\schema.sql
只备份数据mysqldump -u root -p --no-create-info mydb > D:\backup\data.sql
备份指定表mysqldump -u root -p mydb users orders > D:\backup\tables.sql
忽略某表mysqldump -u root -p mydb --ignore-table=mydb.logs > D:\backup\no_logs.sql

定时备份（Windows 批处理）

创建 F:\Tools\mysql_backup_daily.bat：

@echo off
setlocal
set DATE=%date:~0,4%%date:~5,2%%date:~8,2%
set BACKUP_DIR=D:\backup\mysql
if not exist %BACKUP_DIR% mkdir %BACKUP_DIR%

cd F:\Tools\mysql-8.4.8-winx64\bin
mysqldump -u root -pYourPassword --databases mydb > %BACKUP_DIR%\mydb_%DATE%.sql

:: 删除 7 天前的备份
forfiles /p %BACKUP_DIR% /m *.sql /d -7 /c "cmd /c del @path" 2>nul
echo Backup completed: mydb_%DATE%.sql
在 taskschd.msc（任务计划程序）中创建每日定时任务执行此脚本。

恢复数据

场景命令（CMD 下执行）
恢复到指定库mysql -u root -p mydb < D:\backup\mydb.sql
恢复含建库语句的备份mysql -u root -p < D:\backup\mydb_full.sql
恢复所有数据库mysql -u root -p < D:\backup\all.sql

12. 数据导入导出

SELECT INTO OUTFILE（导出 CSV）

-- 需要 FILE 权限
SELECT * FROM users
INTO OUTFILE 'D:/backup/users.csv'
FIELDS TERMINATED BY ','
ENCLOSED BY '"'
LINES TERMINATED BY '\n';

LOAD DATA INFILE（从 CSV 导入）

LOAD DATA INFILE 'D:/backup/users.csv'
INTO TABLE users
FIELDS TERMINATED BY ','
ENCLOSED BY '"'
LINES TERMINATED BY '\n'
IGNORE 1 ROWS;  -- 跳过表头

13. 性能优化配置

查看运行状态

操作命令
所有配置变量SHOW VARIABLES;
运行状态SHOW STATUS;
InnoDB 状态SHOW ENGINE INNODB STATUS;
当前连接SHOW PROCESSLIST;
最大连接数SHOW VARIABLES LIKE 'max_connections';

慢查询日志

-- 临时开启
SET GLOBAL slow_query_log = ON;
SET GLOBAL long_query_time = 2;  -- 超过 2 秒记录

-- 查看日志位置
SHOW VARIABLES LIKE 'slow_query_log_file';
SHOW STATUS LIKE 'Slow_queries';

在 my.ini 中永久配置：

slow_query_log=1
slow_query_log_file=F:/Tools/mysql-8.4.8-winx64/data/mysql-slow.log
long_query_time=2
log_queries_not_using_indexes=1

执行计划分析

-- 分析 SQL 执行计划
EXPLAIN SELECT * FROM users WHERE username = 'admin';

-- JSON 格式详细分析
EXPLAIN FORMAT=JSON SELECT * FROM users WHERE age > 18;

-- 实际执行分析（MySQL 8.0.18+）
EXPLAIN ANALYZE SELECT * FROM users WHERE age > 18;

表维护

操作命令说明
整理碎片OPTIMIZE TABLE users;回收空间，整理索引
更新统计ANALYZE TABLE users;更新索引统计，优化查询计划
检查错误CHECK TABLE users;检测表是否损坏
修复表REPAIR TABLE users;仅 MyISAM 支持

InnoDB 关键参数

[mysqld]
innodb_buffer_pool_size=512M     # 缓冲池（物理内存 50-70%）
innodb_log_file_size=256M         # 日志文件大小
innodb_flush_log_at_trx_commit=2  # 2=性能优先, 1=安全优先
innodb_lock_wait_timeout=50       # 锁等待超时（秒）
innodb_io_capacity=200            # IO 吞吐（SSD 可调高）

InnoDB vs MyISAM

特性InnoDBMyISAM
事务支持✅❌
行级锁✅❌（表锁）
外键✅❌
崩溃恢复✅❌
推荐场景通用 / OLTP只读 / 日志
建议：默认使用 InnoDB，除非在只读数据仓库等特殊场景才考虑 MyISAM。
